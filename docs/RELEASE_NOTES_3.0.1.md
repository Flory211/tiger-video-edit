# Tiger Video Edit 3.0.1 — обновление Windows

Пакет обновления для установленной Windows x64 версии 3.0.0, сборки 3004/3005.
Проверка обновления на копии сборки 3005 пройдена. Первичная установка этим
небольшим пакетом не выполняется. Проекты, настройки, подключение музыки и
совместимые установленные медиакомпоненты сохраняются.

- Быстрый поиск Phonk, Drift phonk, Brazilian phonk, Brazilian funk и Montagem.
- Поиск фонка по-русски, новинки, популярное за месяц и разные исполнители.
- Прокрутка на небольшом экране с клавиатурой и повторный поиск после пустого ответа.

Открой «Обновления» → «Проверить обновления» → «Скачать обновление» →
«Открыть системный установщик». Перед заменой файлов сохрани проект и закрой
редактор. Установщик не закрывает его принудительно. После обновления версия —
3.0.1, сборка 3006. Автоматическая проверка при запуске использует кэш до 24 часов;
ручная кнопка запрашивает свежие данные.

Установщик не содержит частного Client ID Jamendo. Существующая локальная
настройка сохраняется; для первоначального подключения нужен Client ID приложения.
Добавление Jamendo в монтаж пока отключено до подтверждения условий сервиса.

141 тест приложения и нативное прослушивание фонка в Windows пройдены.
Проверены отказ для отсутствующей базы, несовместимого движка и открытых файлов,
а также сохранение остальных файлов при обновлении. Архив исходников приложения,
описание источников зависимостей и SHA256SUMS приложены. Windows-установщик без
Authenticode-подписи. Android в этот выпуск не входит.
