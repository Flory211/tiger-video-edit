# Tiger Video Edit 2.0 — использование новых функций

Эта сборка реализует все три выбранных блока: эффекты/пресеты, локальный анализ ритма/автосборку и титры/видео/GIF. Установщики 1.0.1 сохранены отдельно. Остальные пункты большой дорожной карты (многодорожечный звук, онлайн-источники, дополнительные форматы вывода и т. п.) относятся к следующим обновлениям.

## Эффекты и пресеты

Выберите медиа в библиотеке и прокрутите правую панель «Свойства» до «Эффекты». Доступны Shake, Zoom, Blur, Glow, Flash, RGB Split и Glitch; их можно комбинировать. Ползунки регулируют силу, отдельный ползунок — длительность после начала каждого интервала. При повторном появлении медиа эффект запускается заново от маркера. В режиме настройки выбранного изображения показывается начало эффекта; Play возвращает просмотр результата.

Выпадающий список содержит готовые пресеты. «Применить» меняет выбранное медиа, «Пресет для всех» применяет его ко всей библиотеке. «Сохранить текущие» сохраняет именованный пользовательский пресет локально; одинаковое имя заменяет прежний. «Текущие эффекты для всех» копирует ваши настройки. Undo/Redo поддерживаются для изменений проекта.

## Ритм и автосборка

Добавьте музыку и медиа. Нажмите значок волшебных искр над таймлайном или меню ⋮ → «Ритм и автосборка». Выберите чувствительность и запустите анализ. Приложение ищет выраженные звуковые атаки локально и показывает количество точек и оценку BPM, если темп достаточно устойчив.

Кнопка «Автосборка» заменяет маркеры найденными точками внутри выбранного отрывка и использует существующий порядок медиа. Изменение отменяется одним Undo. Алгоритм не является музыкальным экспертом: акценты голоса, шум и другие громкие звуки могут давать лишние точки, возможна ошибка вдвое по темпу. Все маркеры можно исправить вручную. На тишине сетка не выдумывается.

## Видео и GIF

«Добавить медиа» принимает фотографии, GIF, MP4, MOV, MKV, WEBM и M4V при наличии декодера. Картинки/видео/GIF можно смешивать и переставлять в одной библиотеке. Для видео/GIF в свойствах задаётся начало исходного фрагмента. Короткое медиа повторяется до следующего музыкального маркера; каждый новый интервал начинается с выбранного смещения. Звук видеофрагмента не смешивается с музыкальной дорожкой.

Кодеки зависят от платформы. Windows декодирует через вложенный FFmpeg; Android использует системный MediaMetadataRetriever/MediaCodec. Ошибки декодирования показываются пользователю. Видео с метаданными поворота сохраняет правильные пропорции. Для стабильных кадров Windows использует фиксированные секундные точки перемотки; скорость поиска также зависит от ключевых кадров исходника.

## Титры

В правых свойствах ниже эффектов — раздел «ТИТРЫ». Добавьте надпись, задайте начало и конец в секундах исходной музыки, позицию X/Y (0–1), размер и цвет. Можно редактировать и удалять отдельные надписи. Последний момент интервала не включается: титр виден при start ≤ t < end. Координаты и размер масштабируются вместе с форматом проекта, отдельно для 16:9 и 9:16.

## Сохранение и экспорт

Расширение остаётся `.tve`, схема JSON теперь версии 2. Старые `.tve`/`.leos` версии 1 читаются автоматически. Старая программа 1.0.1 не читает схему v2; предыдущая исправная копия сохраняется в `.bak`.

Предпросмотр и экспорт используют общий Canvas-композитор и одно расписание 30 FPS. Эффекты и титры рассчитываются по кадру, без случайного таймера. Проекты с анимацией/эффектами/титрами готовят временные PNG-кадры, затем кодируются в MP4. Это медленнее статичного экспорта и требует свободного места: сотни мегабайт или больше для длинных/детальных проектов. Прогресс и отмена работают; временная папка удаляется. Статичные проекты без новых элементов сохраняют прежний быстрый путь экспорта.

Предпросмотр тяжёлых видео может пропускать визуальные кадры, следуя времени аудиопроигрывателя; экспорт рассчитывает каждый кадр. Работа Android-кодировщиков и точность Android-вывода требуют отдельной проверки на устройстве.

## Собственный пример

Откройте `demo/Pulse-v2.tve`: оригинальные изображения, синтетическая музыка, видео и GIF, сочетания эффектов и два титра. `node tools/generate-v2-demo.cjs` воспроизводит пример; `flutter test tools/render_v2_demo_test.dart` создаёт проверенный `demo/Pulse-v2.mp4`.
