## 3. GITHUB ACTIONS — АВТОМАТИЧЕСКИЕ СБОРКИ

Настрой CI/CD на GitHub Actions.

Нужны две независимые сборки:

### Windows Build

Используй совместимый Windows runner.

Процесс:

1. Получение исходного кода.
2. Установка нужного SDK.
3. Установка зависимостей.
4. Анализ кода.
5. Запуск тестов.
6. Сборка Windows Release.
7. Создание полноценного установщика EXE.
8. Проверка наличия основных файлов установочного пакета.
9. Загрузка установщика в GitHub Actions Artifacts.

Используй подходящий инструмент создания установщика, например Inno Setup, если он совместим с проектом.

Установщик должен содержать реальные библиотеки, необходимые для работы приложения.

### Android Build

Используй совместимый runner с Android SDK и JDK.

Процесс:

1. Получение исходного кода.
2. Установка SDK и зависимостей.
3. Анализ и тестирование.
4. Сборка APK.
5. Проверка целостности APK.
6. Подписание релизной сборки настроенным ключом.
7. Публикация артефакта.

Не храни ключи подписи и пароли в репозитории.

Используй GitHub Actions Secrets.

Если релизный ключ отсутствует, не выдавай debug APK за финальный релиз. Подготовь инструкции безопасной настройки подписи.

Для первой версии автоматизации допустимо собрать тестовый APK отдельно от подписанного релиза.

### Запуск workflows

Проверки должны запускаться:

- При Pull Request.

- Вручную через workflow_dispatch.

## 7. ОБЩИЕ ЭФФЕКТЫ ДЛЯ ВСЕГО ВИДЕО

**ЭТО ОДНА ИЗ ГЛАВНЫХ НОВЫХ ФУНКЦИЙ.**

Сейчас пользователь может применять эффекты к отдельным изображениям или клипам, если эта функция уже реализована.

В версии 3.0 необходимо добавить полноценные глобальные эффекты.

Пользователь должен иметь возможность применить эффект:

1. К одному изображению.
2. К нескольким выбранным изображениям.
3. Ко всем изображениям проекта.
4. Ко всей итоговой видеокомпозиции.
5. К выбранному временному диапазону.
6. К определённым музыкальным маркерам.

### Пример

Пользователь добавил 20 картинок.

Он выбирает эффект Shake.

Нажимает:

«Применить ко всем».

Эффект появляется на всех изображениях.

При этом пользователь может в дальнейшем изменить силу эффекта на отдельной картинке.

Реализуй два разных способа:

**Bulk Apply** — массовое добавление экземпляров эффекта к выбранным клипам.

**Global Adjustment Layer** — один эффект над всей композицией, действующий на всё видео или заданный временной диапазон.

Эти механизмы не должны путаться между собой.

### Режимы применения

- Всегда.
- На каждом маркере.
- На выбранных маркерах.
- Только при смене изображения.
- Только в выбранном диапазоне.

### Настройки

- Сила эффекта.
- Продолжительность.
- Частота.
- Задержка.
- Начальная и конечная интенсивность.
- Плавность.
- Кривая изменения.

Добавь возможность временно выключить глобальные эффекты одной кнопкой.

Обеспечь одинаковое применение эффектов в предпросмотре и экспорте.
