# Jamendo в Tiger Video Edit

В «Музыка» нажми «Онлайн». Экран ищет настоящие треки Jamendo по названию, исполнителю и настроению; доступны жанры, страницы результатов, прослушивание, избранное и история. До нажатия «Найти» запросов в каталог нет. Поиск кэшируется только в памяти на две минуты, максимум восемь запросов; это не скачанная офлайн-библиотека. Пустой запрос показывает популярные треки.

Раскрой карточку: там автор, лицензия, ссылка на источник и кнопка копирования авторства. Избранное и история сохраняют сведения о треках, а не аудиофайлы. Онлайн-поток требует интернета. Локальная музыка и проекты работают самостоятельно.

В 3.0.1 добавлены быстрые запросы «Фонк», «Brazilian funk», «Brazilian phonk», «Drift phonk» и «Montagem». Кнопки листаются горизонтально. Запросы «фонк», «дрифт фонк» и «бразильский фонк» также понимаются по-русски. Для фонка используется поиск по названиям: общий поиск Jamendo иногда пропускает эти записи. Сочетания drift/Brazilian дополнительно уточняют запрос. Brazilian funk остаётся широким поиском сервиса и может включать соседние стили; кнопки не гарантируют жанр каждой записи.

Можно выбрать «Сначала новые» или «Популярное за месяц». «Разные авторы» показывает по одному треку каждого исполнителя: выключи этот фильтр, чтобы видеть остальные композиции того же автора. После изменения настроек нажми «Найти». Страницы сохраняют параметры последнего успешного поиска; стрелка вправо открывает следующие результаты. Число внизу обозначает треки на текущей странице, а не размер всей библиотеки. Быстрый запрос сбрасывает прежний жанр и фильтр CC BY/CC0, чтобы они случайно не скрыли фонк.

Перед прослушиванием обновляются сведения о треке, включая записи из избранного. Поток проходит через временный локальный сервер: адрес каждого внешнего перенаправления проверяется приложением, декодер получает только локальный MP3-поток. Дисковый аудиокэш отключён. Остановка закрывает соединения; завершение и ошибка сбрасывают кнопку Play. История пополняется после начала декодирования звука.

## Подключение

Нажми шестерёнку и введи Client ID зарегистрированного приложения Jamendo. Client Secret, пароль и OAuth-доступ к пользовательскому аккаунту не используются. Идентификатор хранится в отдельном локальном `jamendo-settings.json` рядом с музыкальной библиотекой и не включается в `.tve`.

Для частной сборки разработчика используется игнорируемый JSON с ключом `TVE_JAMENDO_CLIENT_ID` и `--dart-define-from-file`. Публичная CI-сборка не содержит Client ID; подключение выполняется на устройстве. Идентификатор из портала не добавлен в исходники/GitHub. Секрет приложения не сохранялся.

## Добавление в монтаж

Эта часть ожидает подтверждения Jamendo именно для использования выбранной композиции как материала проекта и экспорта видео. Создание Client ID и разрешение автора скачать трек не заменяют это уточнение. В текущей сборке поиск/прослушивание доступны, а «В проект» объясняет причину недоступности. Пользовательской галочки, которая самовольно снимает ограничение, нет.

Подготовлен защищённый путь добавления: только CC BY/CC0 и разрешённое автором скачивание; свежая проверка метаданных перед загрузкой; HTTPS и проверка домена каждого перенаправления; ограничения размера/времени; отмена и очистка временного файла. После подтверждения условий дистрибьютор может активировать этот путь в отдельной проверенной сборке. Не активировать `TVE_JAMENDO_EDITING_APPROVED` без документированного разрешения.

Выбранное аудио передаётся существующему механизму материалов проекта, а не в локальную музыкальную коллекцию. Сведения об авторстве сохраняются в `.tve`, сохраняются при Undo/Redo и показываются перед экспортом с кнопкой копирования. Для старых проектов поле пустое. NC/ND/SA не объявляются автоматически подходящими для видеопубликации; первая версия отбора поддерживает CC BY/CC0.

После начала передачи материала в проект отмена недоступна до завершения операции. Восстановление отсутствующего файла в редакторе предполагает выбор того же исходного трека: программа не распознаёт подмену другим аудио и сохраняет прежнее авторство.

Необработанные сетевые исключения и адреса запросов с Client ID не показываются в сообщениях об ошибках. При отсутствии сети/ошибке API можно повторить поиск; локальные материалы не удаляются.

## Источники и проверки

- Параметры API: https://developer.jamendo.com/v3.0/tracks . Для обоих типов записи используется `type=single albumtrack`, а не `all`.
- Условия API: https://devportal.jamendo.com/api_terms_of_use . Кэширование должно быть необходимо для работы приложения; наш сценарий монтажа/сохранения требует уточнения.
- CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ . Требуются авторство, ссылка на лицензию и указание изменений.

Проверки провайдера/интерфейса: `test/jamendo_test.dart`, `test/jamendo_page_test.dart`. Нативный поиск/поток и снимки двух размеров проверяются отдельно в `native_test/integration_test/jamendo_live_test.dart` с приватной конфигурацией; сетевой тест не запускается в публичном CI без настройки. Обычные тесты используют явно синтетические ответы.

Проверка 19 ноября 2026: 139/139 общих тестов прошли, включая 18 проверок Jamendo. Нативный Windows-тест прошёл с настоящим API и обычным проигрывателем страницы: кнопка «Фонк», реальные результаты, Play, положительная позиция декодирования, остановка, размеры 1400×1000 и 390×844, отсутствие скачанных MP3/временных файлов. Это проверка Windows; запуск на Android-устройстве ещё не выполнен.
